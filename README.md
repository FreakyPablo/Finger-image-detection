# Finger-image-detection
Un programme permettant de compter le nombre de doigts sur une image.

## Prérequis 
- bibliothèque numpy 
```sh 
pip install numpy 
```
- bibliothèque OpenCV
```sh 
pip install opencv-python
```

## RoadMap 
- #### Changement de la méthode de détection des doigts
Méthode détection améliorable, loupe parfois un doigt si il est trop petit 

- Prise en charge d'un flux vidéo en direct
